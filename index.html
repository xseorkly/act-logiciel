Contexte & Défi

Chaque année, des dizaines d'attestations de formation, de diplômes ou de certificats doivent être générés manuellement — un travail répétitif, chronophage et source d'erreurs.

Votre mission : concevoir, avec l'aide d'une IA générative, une petite application locale qui lit un fichier Excel contenant les données des participants (nom, prénom, formation, date…) et génère automatiquement un document personnalisé (PDF ou Word) pour chacun d'eux.

Vous n'avez pas besoin d'être développeur. L'IA est là pour vous guider, écrire le code, corriger les erreurs et vous expliquer chaque étape. Votre rôle : poser les bonnes questions et piloter le projet.

02

Déroulement de l'activité

1
🎨 Choisir votre document & préparer les données
Décidez ensemble du type de document à générer : attestation de formation, diplôme, certificat de participation… Listez les champs nécessaires (nom, prénom, date, intitulé de formation, signature…) et créez votre fichier Excel exemple avec 5 à 10 lignes fictives.
⏱ ~20 min
2
🤖 Premier échange avec l'IA
Ouvrez l'IA de votre choix (ChatGPT, Claude, Gemini…) et demandez-lui de vous aider à créer un programme capable de lire votre Excel et de générer un document. Commencez simplement, sans tout détailler d'un coup. Notez le code proposé et essayez de le comprendre avec l'aide de l'IA.
⏱ ~30 min
3
🧪 Tester & déboguer en équipe
Exécutez le code sur vos machines. Il y aura probablement des erreurs — c'est normal et formateur ! Copiez le message d'erreur et renvoyez-le à l'IA pour qu'elle vous aide à corriger. Recommencez jusqu'à ce que les documents se génèrent correctement.
⏱ ~40 min
4
✨ Améliorer le rendu visuel
Les documents fonctionnent ? Passez au niveau suivant : demandez à l'IA d'améliorer la mise en page (logo fictif, couleurs, cadre, signature…). Ajoutez un titre élégant, une bordure, un texte de félicitations. Votre document doit ressembler à un vrai certificat !
⏱ ~30 min
5
🖥 (Optionnel) Créer une petite interface
En bonus, demandez à l'IA de créer une interface graphique simple (en Python avec Tkinter, ou une mini page web) permettant de glisser-déposer le fichier Excel et de cliquer sur un bouton pour lancer la génération. L'outil devient ainsi utilisable par n'importe qui.
⏱ ~30 min
6
🎤 Présentation des résultats
Chaque groupe présente son outil en 2 à 3 minutes : montrez une démo en direct, expliquez votre approche, partagez un prompt qui a particulièrement bien fonctionné (ou un qui a échoué !). Discutez ensemble de ce que vous feriez différemment.
⏱ ~20 min
03

Ce que vous devez rendre

  • ✓ Le fichier Excel exemple utilisé comme source de données
  • ✓ Le code complet de l'application (script Python ou autre)
  • ✓ 3 exemples de documents générés (PDF ou Word)
  • ✓ Un journal de bord : les prompts clés utilisés et ce qu'ils ont produit
  • ✓ Une capture du moment le plus satisfaisant (ou du bug le plus drôle 😄)
04

Critères d'évaluation

20 % Le programme lit le fichier Excel sans erreur
25 % Les documents sont générés et correctement personnalisés
20 % Qualité visuelle du document produit
20 % Qualité & pertinence des prompts utilisés
15 % Clarté de la présentation & esprit d'équipe
💡
Conseils pour bien travailler avec l'IA

Soyez précis : donnez à l'IA le contexte complet (langage souhaité, structure du fichier Excel, type de document…).

Itérez : ne cherchez pas le prompt parfait du premier coup. Commencez simple, puis affinez.

Copiez les erreurs : quand quelque chose ne marche pas, copiez-collez le message d'erreur exact dans l'IA — elle saura quoi faire.

Demandez des explications : dites à l'IA "explique-moi ce que fait ce code ligne par ligne" — vous apprendrez beaucoup plus vite.

IA suggérées : ChatGPT (chat.openai.com), Claude (claude.ai), Gemini (gemini.google.com), Mistral (chat.mistral.ai)
